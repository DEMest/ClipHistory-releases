# ClipHistory

История буфера обмена, скриншоты и «Сейчас играет» в панели у выреза MacBook — наведите мышь на вырез.
Здесь лежат только готовые сборки.

## Установка

Нужна macOS 14 или новее (Apple Silicon или Intel).

1. Скачайте `ClipHistory-<версия>.zip` из [последнего выпуска](https://github.com/DEMest/ClipHistory-releases/releases/latest), распакуйте и перетащите ClipHistory в «Программы».
2. Откройте. Сборка не нотаризована Apple, поэтому macOS скажет, что не может проверить разработчика → «Готово».
   Затем **System Settings → Privacy & Security** → внизу «ClipHistory was blocked…» → **Open Anyway** → пароль. Это нужно один раз.
3. Чтобы выбранное вставлялось само: **System Settings → Privacy & Security → Accessibility → +** → ClipHistory.

Дальше приложение обновляется само: проверяет новые выпуски раз в несколько часов и ставит их, когда панель закрыта.
Отключить — меню ClipHistory в строке меню → «Настройки» → «Обновлять автоматически».
